# Kedai Kopi Senja

Aplikasi pemesanan menu berbasis React + Vite dan Tailwind CSS.

## Menjalankan aplikasi
1. Pastikan Node.js versi LTS sudah terpasang.
2. Buka terminal di folder proyek.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang ditampilkan Vite.

## Build
Jalankan `npm run build` untuk memeriksa hasil build produksi.

## Fitur
- Filter kategori menu.
- Detail menu tiap kartu dapat dibuka sendiri.
- Menu tidak tersedia tidak dapat ditambahkan.
- Keranjang dengan jumlah dan total harga yang tersinkron.
- Validasi nama, nomor meja, dan pesanan.
- Pesanan berhasil akan menampilkan ucapan terima kasih dan mengosongkan form/keranjang.
